# Heart Bot

내 게시물의 댓글 하트를 확인하고, 이웃의 최근 글에 공감과 자연스러운 Gemini 댓글을 작성하는 Windows 프로그램입니다.

## 다운로드

[최신 버전 설치 파일 다운로드](https://github.com/DOYOUNG5530/heart-bot-releases/releases/latest/download/HeartBotSetup-0.1.2.exe)

설치 파일을 실행한 뒤 안내에 따라 설치하세요. 배포 초기에는 Windows가 게시자를 확인할 수 없다는 경고를 표시할 수 있습니다.

## 처음 실행하기

1. 전달받은 **라이선스 키**와 등록된 **이메일**을 입력합니다.
2. **라이선스 등록**을 누릅니다.
3. 인증되면 이용 기간 동안 같은 Windows 사용자와 PC에서 자동으로 확인됩니다.
4. 이용 기간이 만료되거나 허용된 PC가 아니면 관리자에게 갱신 또는 PC 등록 해제를 요청하세요.

## 기본 설정

프로그램의 `대댓글` 화면에서 다음 항목을 입력합니다.

- **네이버 아이디·비밀번호**: 저장된 Chrome 로그인 세션이 없을 때 사용합니다.
- **Gemini API KEY**: 댓글 생성에 사용할 본인의 Gemini API 키입니다.
- **사용할 AI 모델**: 기본 모델을 사용하거나 이용 가능한 모델 ID를 직접 입력합니다.
- **Chrome 프로필**: 네이버 로그인 상태를 보관할 전용 폴더입니다. 기본값을 그대로 사용해도 됩니다.
- **작업할 내 게시물 URL**: 게시물 주소를 한 줄에 하나씩 입력합니다. 블로그 홈이 아닌 개별 게시물 주소를 사용하세요.

입력이 끝나면 **설정 저장**을 누릅니다. `비밀번호와 API 키 저장`을 선택하면 다음 실행 때 이 PC에서 다시 입력하지 않아도 됩니다. 여러 사람이 함께 쓰는 PC에서는 선택하지 않는 것을 권장합니다.

## 댓글 작업 실행

1. 작업할 게시물 URL이 올바른지 확인합니다.
2. **작업 시작**을 누릅니다.
3. Chrome 로그인 또는 추가 인증이 필요하면 열린 브라우저에서 직접 완료합니다.
4. 로그인이 끝나면 프로그램의 **브라우저 로그인 완료**를 누릅니다.
5. 오른쪽 **실시간 진행 로그**에서 처리 상황을 확인합니다.

작업은 다음 순서로 진행됩니다.

1. 입력한 내 게시물의 댓글을 확인합니다.
2. 아직 누르지 않은 댓글 하트를 누르고 이웃 목록을 만듭니다.
3. 이웃별 최근 게시물을 확인합니다.
4. 처리 가능한 글 한 개에 공감하고 본문에 맞는 Gemini 댓글을 등록합니다.

이미 처리한 댓글·게시물이나 상태를 확실히 확인할 수 없는 화면은 중복 동작을 막기 위해 건너뜁니다.

## 중지와 종료

- 실행 중 **중지**를 누르면 다음 브라우저 동작과 댓글 등록을 중단합니다.
- 진행 중인 페이지 이동이나 API 응답이 끝날 때까지 잠시 기다릴 수 있습니다.
- 창의 닫기 버튼을 누르면 중앙에 종료 확인 창이 표시됩니다.
- 작업 중 종료하면 안전한 중지 절차 후 Chrome을 정리합니다.

## 업데이트

화면 상단의 **업데이트 확인**을 누르면 새 버전을 확인합니다.

- 최신 버전이면 현재 버전이 최신이라는 안내가 표시됩니다.
- 새 버전이 있으면 다운로드 여부를 묻습니다.
- 설치 파일의 SHA-256 무결성 검사를 통과한 경우에만 설치를 실행합니다.
- 업데이트 후에도 이 PC에 저장된 설정, 로그, 라이선스 정보는 유지됩니다.

## 문제가 발생할 때

- **라이선스가 만료됨**: 관리자에게 이용 기간 갱신을 요청하세요.
- **라이선스 PC 수 초과**: 이전 PC 등록 해제를 관리자에게 요청하세요.
- **네이버 로그인이 반복됨**: 같은 Chrome 프로필을 사용하는 다른 Chrome 창을 닫고 다시 실행하세요.
- **추가 인증 또는 보안 확인**: 브라우저에서 직접 완료한 뒤 `브라우저 로그인 완료`를 누르세요.
- **Gemini 댓글 생성 실패**: API 키, 모델 ID, API 사용량과 할당량을 확인하세요. 계속 실패한 이웃은 어색한 대체 댓글을 남기지 않고 건너뜁니다.
- **게시물 URL 오류**: `blog.naver.com/블로그ID/게시물번호` 형식의 개별 게시물 주소인지 확인하세요.
- **화면 변경으로 동작하지 않음**: 네이버 화면 구조가 바뀌었을 수 있습니다. 오른쪽 로그를 확인해 관리자에게 전달하세요.

설정과 실행 로그는 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\NaverHeartBot\config.json
%LOCALAPPDATA%\NaverHeartBot\run.log
```

오류 문의 시 비밀번호와 API 키는 보내지 말고, `run.log`에서 필요한 오류 구간만 확인해 전달하세요.
